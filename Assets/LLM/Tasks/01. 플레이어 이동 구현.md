# Task 01. 플레이어 이동 구현

## 목표
- `JC_PlayerController`를 만들어 플레이어가 XY 평면에서만 이동하도록 구현한다.

## 구현 대상
- 클래스: `JC_PlayerController`
- 입력: Old Input System의 수평/수직 입력
- 이동 조건:
  - X, Y만 이동한다.
  - Z는 고정한다.
  - 대각선 이동은 정규화한다.

## 작업 내용
- 플레이어 오브젝트에 `JC_PlayerController`를 붙인다.
- 이동 속도를 Inspector에서 조절 가능하게 둔다.
- `Horizontal`, `Vertical` 입력으로 이동 벡터를 만든다.
- 입력이 없으면 즉시 멈추도록 처리한다.
- 이동 후 Z값이 변하지 않도록 보정한다.

## 에디터 테스트 흐름
- 플레이어 오브젝트 하나만 씬에 둔다.
- 카메라는 Orthographic 탑뷰 구도로 고정한다.
- 플레이 모드에서 상하좌우와 대각선 이동을 확인한다.

## 완료 기준
- 이동 반응이 즉시 보인다.
- 플레이어가 XY 평면 밖으로 벗어나지 않는다.
- 대각선 이동 속도가 과하게 빨라지지 않는다.
