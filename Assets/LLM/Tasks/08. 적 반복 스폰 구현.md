# Task 08. 적 반복 스폰 구현

## 목표
- `JC_EnemySpawner`를 만들어 적이 일정 시간마다 반복 생성되도록 한다.

## 구현 대상
- 클래스: `JC_EnemySpawner`
- 동작 조건:
  - 적 생성 간격은 최소 시간과 최대 시간 사이에서 랜덤으로 정한다.
  - 기본값은 최소 1초, 최대 3초를 사용한다.
  - 적 프리팹과 스폰 위치는 Inspector에서 연결한다.

## 작업 내용
- 씬 또는 전용 스포너 오브젝트에 `JC_EnemySpawner`를 붙인다.
- 적 프리팹 참조와 스폰 기준점 배열 또는 단일 기준점을 Inspector에 노출한다.
- 다음 스폰 시간을 매번 랜덤 범위로 다시 계산한다.
- 전투 중 적이 끊기지 않게 반복 생성한다.
- 필수 참조가 비어 있을 때 바로 알 수 있는 단순한 안전 처리도 둔다.

## 에디터 테스트 흐름
- 플레이 시작 후 적이 자동으로 등장하는지 확인한다.
- 10초 정도 두고 스폰 간격이 1초~3초 사이에서 바뀌는지 본다.
- 스포너 참조가 비었을 때 어디가 비었는지 바로 알 수 있는지 확인한다.

## 완료 기준
- 적이 일정 시간마다 반복 생성된다.
- 스폰 간격이 최소/최대 범위 안에서 랜덤하게 바뀐다.
- 전투 루프에 적 수급이 자연스럽게 추가된다.
