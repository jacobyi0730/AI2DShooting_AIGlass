# Task 02. 플레이어 발사 구현

## 목표
- `JC_PlayerShooter`, `JC_BulletSpawnPoint`를 만들어 플레이어가 화면 위쪽으로 총알을 발사하게 한다.

## 구현 대상
- 클래스: `JC_PlayerShooter`
- 클래스: `JC_BulletSpawnPoint`
- 발사 조건:
  - 공격 입력 시 즉시 발사한다.
  - 발사 위치는 플레이어 앞쪽 기준점에서 가져온다.
  - 연사 간격은 Inspector에서 조절한다.

## 작업 내용
- 플레이어 오브젝트에 `JC_PlayerShooter`를 붙인다.
- 자식 오브젝트 또는 별도 기준점에 `JC_BulletSpawnPoint`를 둔다.
- 공격 입력 키를 정하고 Old Input System으로 읽는다.
- 총알 프리팹 참조와 연사 간격 값을 Inspector에 노출한다.
- 발사 방향은 화면 위쪽 고정으로 처리한다.

## 에디터 테스트 흐름
- Task 01의 이동이 유지되는 상태에서 발사 기능을 추가한다.
- 발사 입력을 눌렀을 때 총알 프리팹이 즉시 생성되는지 확인한다.
- 발사 위치가 플레이어 중심과 겹치지 않는지 확인한다.

## 완료 기준
- 이동 중에도 발사가 자연스럽게 동작한다.
- 연사 간격이 설정값대로 유지된다.
- 총알이 항상 같은 방향으로 생성된다.
