# Task 03. 플레이어 총알 이동과 정리 구현

## 목표
- `JC_PlayerBullet`을 만들어 총알이 위쪽으로 이동하고 화면 밖에서 정리되게 한다.

## 구현 대상
- 클래스: `JC_PlayerBullet`
- 동작 조건:
  - 생성 즉시 위쪽으로 이동한다.
  - 속도는 고정값을 사용한다.
  - 전장 밖으로 나가면 제거한다.

## 작업 내용
- 총알 프리팹에 `JC_PlayerBullet`을 붙인다.
- 총알 이동 속도를 Inspector에서 조절 가능하게 둔다.
- 매 프레임 위쪽 방향으로 이동시킨다.
- 간단한 전장 경계 기준 또는 화면 이탈 기준으로 총알 제거 조건을 둔다.

## 에디터 테스트 흐름
- Task 02 발사 기능이 연결된 상태에서 플레이한다.
- 발사 직후 총알이 위로 곧바로 이동하는지 확인한다.
- 여러 발을 쏴도 속도와 방향이 일정한지 확인한다.
- 화면 밖 총알이 계속 남지 않는지 확인한다.

## 완료 기준
- 총알이 항상 위쪽으로만 이동한다.
- 총알 속도가 프레임에 따라 흔들리지 않는다.
- 화면 밖 총알이 정상 정리된다.
