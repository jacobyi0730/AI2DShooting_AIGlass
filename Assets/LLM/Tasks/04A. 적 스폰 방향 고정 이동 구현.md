# Task 04A. 적 스폰 방향 고정 이동 구현

## 목표
- `JC_EnemyController`를 확장해 적이 스폰 시점에 한 번만 방향을 정하고, 이후에는 그 방향으로만 계속 이동하게 한다.
- 이 Task는 Task 04의 지속 추적형 이동과 별개의 고정 방향 이동 규칙을 다룬다.

## 구현 대상
- 클래스: `JC_EnemyController`
- 보조 참조: `JC_EnemyTargetTracker`
- 동작 조건:
  - 적은 스폰 시점에 한 번만 이동 방향을 결정한다.
  - 30% 확률이면 플레이어가 있던 방향을 사용한다.
  - 70% 확률이면 아래 방향(`Vector3.down`)을 사용한다.
  - 스폰 이후에는 플레이어가 움직여도 방향을 바꾸지 않는다.
  - XY 평면만 사용하고 Z는 고정한다.

## 작업 내용
- `JC_EnemyController`에 적 이동 모드 개념을 추가한다.
- 기존 추적형 이동은 그대로 유지하고, 고정 방향 이동 모드를 별도로 둔다.
- 고정 방향 이동 모드에서는 `Awake()` 시점에 한 번만 방향을 캐시한다.
- 플레이어 참조가 없거나 플레이어와 같은 위치면 아래 방향으로 안전하게 폴백한다.
- Inspector에서 이동 속도와 함께 이동 모드를 확인할 수 있게 둔다.

## 에디터 테스트 흐름
- 적 오브젝트 또는 적 프리팹의 이동 모드를 `FixedSpawnDirection`으로 바꾼다.
- 같은 적을 여러 개 배치하거나 반복 스폰해 시작 방향 분포를 본다.
- 일부 적은 플레이어 방향으로, 나머지는 아래 방향으로 출발하는지 확인한다.
- 플레이어를 이동시켜도 이미 움직이기 시작한 적 방향이 바뀌지 않는지 확인한다.

## 완료 기준
- 적이 스폰 시점에 한 번만 방향을 결정한다.
- 고정 방향 이동 중에는 플레이어 위치 변화가 이동 방향에 영향을 주지 않는다.
- Task 04의 추적형 이동과 선택적으로 공존할 수 있다.
