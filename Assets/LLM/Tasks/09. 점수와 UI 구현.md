# Task 09. 점수와 UI 구현

## 목표
- `JC_ScoreManager`, `JC_ScoreTextBinder`를 만들어 적 처치 점수를 누적하고 우측 상단 UI에 표시한다.

## 구현 대상
- 클래스: `JC_ScoreManager`
- 클래스: `JC_ScoreTextBinder`
- 동작 조건:
  - 총알로 적을 파괴할 때마다 점수를 1점 얻는다.
  - 점수는 전투 시작 시 0점이다.
  - 점수 UI는 화면 우측 상단에 배치한다.

## 작업 내용
- 점수 누적용 매니저를 만든다.
- 적 제거 처리와 점수 증가 연결 지점을 정한다.
- UI Text 또는 TMP Text를 이용해 현재 점수를 표시한다.
- 우측 상단에 점수 UI 배치를 고정한다.
- 한 적에서 점수가 중복 증가하지 않도록 단순한 보호 규칙을 둔다.

## 에디터 테스트 흐름
- 적을 1마리 제거했을 때 점수가 1 오르는지 확인한다.
- 연속 처치 시 점수가 누락 없이 계속 증가하는지 본다.
- 우측 상단 UI가 전투 중에도 잘 보이는지 확인한다.

## 완료 기준
- 적 처치마다 점수가 1점씩 오른다.
- 점수 UI가 우측 상단에서 안정적으로 갱신된다.
- 충돌 제거와 점수 처리 사이에 중복 증가 문제가 없다.
