# Task 10. 배경 스크롤 구현

## 목표
- `JC_BackgroundScroller`를 만들어 숲 전투 현장 배경을 세로 방향으로 UV 스크롤한다.

## 구현 대상
- 클래스: `JC_BackgroundScroller`
- 배경 리소스: `Assets/Texture/background.png`
- 동작 조건:
  - 하나의 배경 이미지를 사용한다.
  - UV 애니메이션으로 세로 방향 스크롤을 처리한다.
  - 전투 가독성을 해치지 않는 속도로 움직인다.

## 작업 내용
- 배경용 Quad 또는 Plane 머티리얼에 스크롤 가능한 텍스처를 연결한다.
- `JC_BackgroundScroller`에서 UV Offset을 갱신한다.
- 스크롤 속도를 Inspector에서 조절 가능하게 둔다.
- 숲 느낌의 전투 현장 이미지를 배경 텍스처로 저장한다.
- 반복 이음새가 크게 거슬리지 않게 단순한 패턴을 사용한다.

## 에디터 테스트 흐름
- 플레이 시작 직후 배경이 세로 방향으로 흐르는지 확인한다.
- 스크롤 속도를 바꿔도 전투 오브젝트 가독성이 유지되는지 본다.
- 텍스처 반복 이음새가 플레이 중 거슬리지 않는지 확인한다.

## 완료 기준
- 배경이 세로 방향으로 자연스럽게 스크롤한다.
- 숲 전투 현장 분위기가 전투 판독성을 해치지 않는다.
- 배경 텍스처와 스크롤 로직이 한 번에 연결된다.
