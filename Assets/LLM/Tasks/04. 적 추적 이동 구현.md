# Task 04. 적 추적 이동 구현

## 목표
- `JC_EnemyController`, `JC_EnemyTargetTracker`를 만들어 적이 플레이어를 향해 XY 평면에서 추적 이동하게 한다.
- 이 Task는 적이 살아 있는 동안 계속 플레이어를 따라가는 기본 추적형 이동 규칙을 다룬다.

## 구현 대상
- 클래스: `JC_EnemyController`
- 클래스: `JC_EnemyTargetTracker`
- 동작 조건:
  - 플레이어 참조가 있으면 즉시 추적한다.
  - XY 평면만 사용한다.
  - 여러 적이 있어도 동일하게 동작한다.

## 작업 내용
- 적 프리팹 또는 적 오브젝트에 `JC_EnemyController`를 붙인다.
- 플레이어 Transform 참조를 전달하는 `JC_EnemyTargetTracker`를 붙인다.
- 적 이동 속도를 Inspector에서 조절 가능하게 둔다.
- 플레이어 방향 벡터를 구해 단순 이동한다.
- Z값이 바뀌지 않도록 고정한다.

## 에디터 테스트 흐름
- 플레이어와 적 1개를 씬에 배치해 추적 이동을 확인한다.
- 이후 적 수를 2~3개로 늘려 기본 추적이 유지되는지 본다.
- 플레이어가 이동할 때 적의 이동 방향이 즉시 따라오는지 확인한다.

## 완료 기준
- 적이 항상 플레이어 방향으로 이동한다.
- 적 이동이 XY 평면에 고정된다.
- 적 수가 늘어나도 기본 동작이 깨지지 않는다.
