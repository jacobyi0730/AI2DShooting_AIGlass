# Task 05. 플레이어 체력과 적 접촉 피해 구현

## 목표
- `JC_Health`, `JC_DamageOnContact`를 만들어 적과의 접촉이 플레이어 HP 감소로 이어지게 한다.

## 구현 대상
- 클래스: `JC_Health`
- 클래스: `JC_DamageOnContact`
- 동작 조건:
  - 적이 플레이어에 닿으면 HP가 감소한다.
  - 같은 접촉에서 피해가 중복으로 폭주하지 않게 한다.
  - HP가 0이 되면 사망 상태를 확인할 수 있어야 한다.

## 작업 내용
- 플레이어 오브젝트에 `JC_Health`를 붙인다.
- 최대 HP와 현재 HP를 단순한 정수 기준으로 관리한다.
- 적 오브젝트에 `JC_DamageOnContact`를 붙인다.
- 태그 또는 레이어 기준으로 플레이어 충돌만 처리한다.
- HP가 0이 되면 제거 또는 비활성 중 하나로 단순 처리한다.

## 에디터 테스트 흐름
- Task 04의 적 추적 상태에서 플레이어와 적이 실제로 닿게 만든다.
- 1회 충돌 시 HP가 1회 감소하는지 확인한다.
- 여러 번 충돌시 사망 처리까지 이어지는지 본다.

## 완료 기준
- 적 접촉 시 플레이어 HP가 즉시 감소한다.
- HP 감소가 한 번의 접촉에서 비정상적으로 중복되지 않는다.
- HP 0 상태를 플레이 중 확인할 수 있다.
