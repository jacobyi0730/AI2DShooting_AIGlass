# Task 10. UI 개선 요청

## 목표
- 플레이어 체력을 월드 스페이스 Slider UI로 표시한다.
- 점수 UI를 TMP 기반 텍스트로 전환한다.

## 구현 대상
- 클래스: `JC_Health`
- 클래스: `JC_ScoreTextBinder`
- 동작 조건:
  - 체력 UI는 `Player` 게임오브젝트에 붙은 상태로 함께 이동한다.
  - 체력 UI는 `World Space` Canvas 위의 Slider로 표시한다.
  - 점수 UI는 TMP 텍스트로 우측 상단에 표시한다.

## 작업 내용
- `JC_Health`에서 체력 변경 이벤트와 UI 갱신 지점을 정리한다.
- `Player` 하위에 월드 스페이스 Canvas와 Slider를 런타임 생성한다.
- 체력 값이 바뀔 때 Slider 값이 즉시 반영되도록 연결한다.
- `JC_ScoreTextBinder`의 표시 컴포넌트를 `TextMeshProUGUI`로 전환한다.
- 점수 UI가 기준 해상도 `768 x 1024`에서도 안정적으로 보이도록 Canvas 스케일 기준을 맞춘다.

## 에디터 테스트 흐름
- 플레이어가 피해를 받을 때 체력 바가 줄어드는지 확인한다.
- 플레이어 이동 중에도 체력 바가 머리 위에 붙어서 따라오는지 본다.
- 적 처치 시 TMP 점수 UI가 우측 상단에서 정상 갱신되는지 확인한다.

## 완료 기준
- 플레이어 체력이 Slider UI로 보인다.
- 체력 UI가 플레이어와 함께 이동한다.
- 점수 UI가 TMP 기반으로 정상 표시된다.
