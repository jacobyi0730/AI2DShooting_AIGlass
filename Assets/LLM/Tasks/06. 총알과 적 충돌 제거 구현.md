# Task 06. 총알과 적 충돌 제거 구현

## 목표
- `JC_DestroyOnHit`를 중심으로 총알과 적 충돌 시 양쪽이 자연스럽게 제거되도록 만든다.

## 구현 대상
- 클래스: `JC_DestroyOnHit`
- 충돌 조건:
  - 플레이어 총알이 적과 닿으면 총알이 제거된다.
  - 플레이어 총알이 적과 닿으면 적도 제거된다.
  - 적이 플레이어와 닿았을 때 적 제거 처리도 함께 정리한다.

## 작업 내용
- 총알과 적 프리팹의 충돌 판정을 확인한다.
- 충돌 상대를 태그 또는 레이어로 구분한다.
- 총알 쪽 제거와 적 쪽 제거가 동시에 동작해도 충돌 없이 끝나게 처리한다.
- 플레이어 접촉 시 적 제거 여부도 같은 규칙 안에서 단순하게 맞춘다.

## 에디터 테스트 흐름
- 적 1개를 정면에 두고 총알 발사로 제거되는지 확인한다.
- 연속 발사 중 여러 적이 제거되는지 본다.
- 적이 플레이어에 닿았을 때도 적 제거 흐름이 유지되는지 확인한다.

## 완료 기준
- 총알과 적 충돌 시 양쪽 제거가 즉시 보인다.
- 충돌 처리 중 오류나 중복 제거 문제가 없다.
- 플레이어 접촉과 총알 충돌 결과가 일관되게 유지된다.
