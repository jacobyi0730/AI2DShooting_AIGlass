# Task 07. 전투 씬 연결과 반복 테스트 구성

## 목표
- `JC_GameplaySceneBinder`를 만들어 플레이어, 총알, 적 참조를 한 씬에서 빠르게 연결하고 전투 루프를 반복 테스트할 수 있게 한다.

## 구현 대상
- 클래스: `JC_GameplaySceneBinder`
- 연결 대상:
  - 플레이어
  - 총알 프리팹
  - 적 프리팹 또는 테스트용 적 오브젝트
  - 카메라 및 필수 참조

## 작업 내용
- 씬 시작 시 필수 참조가 비어 있으면 바로 확인할 수 있게 한다.
- 테스트에 필요한 기본 오브젝트 연결을 Inspector 중심으로 단순화한다.
- 플레이어, 발사, 적 접근, 충돌 확인이 한 화면 안에서 이어지도록 배치 기준을 잡는다.
- 10초 내 전투 루프 반복 확인이 가능하도록 최소한의 테스트 구성을 정리한다.

## 에디터 테스트 흐름
- 앞선 Task 구현이 모두 연결된 테스트 씬을 만든다.
- 플레이 시작 직후 이동, 사격, 적 접근, 충돌이 모두 확인되는지 본다.
- 참조 누락 시 어디가 비었는지 바로 찾을 수 있는지 확인한다.

## 완료 기준
- 한 씬에서 기본 전투 루프를 반복 검증할 수 있다.
- 필수 참조 누락을 빠르게 확인할 수 있다.
- 디버그 도구 없이도 플레이 감각 점검이 가능하다.
