# 단계별 수행 절차

현재 체크 상태는 프로젝트 파일 기준이다.
- `[x]`: 실제 구현 또는 설정이 확인된 항목
- `[ ]`: 아직 구현 또는 설정이 확인되지 않은 항목

## 0. 시작 준비
- [ ] Unity에서 테스트용 전투 Scene을 연다.
- [ ] Main Camera를 선택한다.
- [ ] Camera Projection을 `Orthographic`으로 바꾼다.
- [ ] 카메라가 플레이 가능 영역을 세로 화면 기준으로 안정적으로 보이게 위치를 잡는다.
- [ ] Game View 해상도를 `768 x 1024` 기준으로 맞춘다.
- [ ] Hierarchy를 비우지 말고 기본 카메라만 유지한다.

## 1. 플레이어 이동 구성
- [ ] Hierarchy에서 Capsule 오브젝트를 만든다.
- [ ] 오브젝트 이름을 `Player`로 바꾼다.
- [ ] `Player`의 위치를 Scene 중앙 근처로 옮긴다.
- [ ] `Player`의 Z 값을 작업 중 고정값으로 정한다.
- [ ] `Player`에 `JC_PlayerController`를 붙인다.
- [ ] Inspector에서 이동 속도 값을 바로 조절할 수 있게 설정한다.
- [ ] 스크립트가 `Horizontal`, `Vertical` 입력을 읽도록 구현한다.
- [ ] 이동 계산은 X, Y만 바꾸고 Z는 유지되게 처리한다.
- [ ] 대각선 이동 속도가 과하게 빨라지지 않게 방향 벡터를 정규화한다.
- [ ] Play를 누른다.
- [ ] 방향키 또는 WASD로 `Player`를 움직인다.
- [ ] `Player`가 XY 평면에서만 움직이는지 확인한다.
- [ ] 입력을 떼면 즉시 멈추는지 확인한다.

## 2. 플레이어 발사 구성
- [ ] `Player` 아래에 빈 오브젝트를 만든다.
- [ ] 오브젝트 이름을 `BulletSpawnPoint`로 바꾼다.
- [ ] `BulletSpawnPoint`를 `Player`의 앞쪽, 화면 위 방향에 배치한다.
- [ ] `BulletSpawnPoint`에 `JC_BulletSpawnPoint`를 붙인다.
- [ ] `Player`에 `JC_PlayerShooter`를 붙인다.
- [ ] 발사 입력 키를 Old Input 기준으로 정한다.
- [ ] `JC_PlayerShooter`에 총알 프리팹 참조 칸을 만든다.
- [ ] `JC_PlayerShooter`에 발사 간격 값을 Inspector에서 조절 가능하게 만든다.
- [ ] `JC_PlayerShooter`가 `BulletSpawnPoint` 위치에서 총알을 생성하게 구현한다.
- [ ] 총알 발사 방향은 화면 위쪽으로 고정한다.
- [ ] Play를 누른다.
- [ ] 이동 중에 발사 입력을 눌러 본다.
- [ ] 총알이 `Player` 몸통이 아니라 `BulletSpawnPoint` 위치에서 생성되는지 확인한다.
- [ ] 연속 입력 시 발사 간격이 적용되는지 확인한다.

## 3. 플레이어 총알 이동과 정리 구성
- [ ] Sphere 또는 작은 Capsule로 총알용 오브젝트를 만든다.
- [ ] 오브젝트 이름을 `PlayerBullet`로 바꾼다.
- [ ] `PlayerBullet`에 `JC_PlayerBullet`을 붙인다.
- [ ] `JC_PlayerBullet`에 이동 속도 값을 Inspector에 노출한다.
- [ ] `JC_PlayerBullet`이 생성 직후 화면 위쪽으로 전진하게 구현한다.
- [ ] 총알 이동도 프레임 독립적으로 처리한다.
- [ ] 화면 밖으로 나간 총알을 제거하는 조건을 넣는다.
- [ ] `PlayerBullet`를 프리팹으로 저장한다.
- [ ] `JC_PlayerShooter`의 총알 프리팹 칸에 이 프리팹을 연결한다.
- [ ] Play를 누른다.
- [ ] 여러 번 발사해서 총알이 같은 방향으로 계속 나가는지 확인한다.
- [ ] 총알 속도가 프레임에 따라 달라지지 않는지 확인한다.
- [ ] 화면 밖 총알이 계속 남지 않고 정리되는지 확인한다.

## 4. 적 추적 이동 구성
- [ ] Cube 또는 Capsule로 적 오브젝트를 만든다.
- [ ] 오브젝트 이름을 `Enemy`로 바꾼다.
- [ ] `Enemy`를 `Player`와 떨어진 위치에 둔다.
- [ ] `Enemy`에 `JC_EnemyController`를 붙인다.
- [ ] `Enemy`에 `JC_EnemyTargetTracker`를 붙인다.
- [ ] `JC_EnemyTargetTracker`의 대상 참조에 `Player` Transform을 연결한다.
- [ ] `JC_EnemyController`에 이동 속도 값을 Inspector에서 조절 가능하게 만든다.
- [ ] `JC_EnemyController`가 대상이 있으면 `Player` 방향으로 이동하게 구현한다.
- [ ] 적 이동도 XY 평면만 사용하게 처리한다.
- [ ] 적의 Z 값이 흔들리지 않게 고정한다.
- [ ] 필요하면 `Enemy`를 복제해서 2~3개 배치한다.
- [ ] Play를 누른다.
- [ ] `Player`를 이동시키며 적이 바로 추적 방향을 바꾸는지 확인한다.
- [ ] 여러 적이 동시에 있어도 기본 추적이 유지되는지 확인한다.

## 5. 플레이어 체력과 적 접촉 피해 구성
- [ ] `Player`에 체력용 컴포넌트 `JC_Health`를 붙인다.
- [ ] 시작 HP 값을 Inspector에서 설정한다.
- [ ] `Enemy`에 접촉 피해용 컴포넌트 `JC_DamageOnContact`를 붙인다.
- [ ] 접촉 시 줄 피해 값을 Inspector에서 설정한다.
- [ ] `JC_Health`에 HP 감소 함수와 사망 판정 함수를 만든다.
- [ ] HP가 0 이하가 되면 사망 상태가 보이게 처리한다.
- [ ] 프로토타입 단계에서는 `Player` 비활성화 또는 로그 출력 중 하나로 단순 처리한다.
- [ ] `Player`와 `Enemy`에 충돌 판정이 가능한 Collider를 붙인다.
- [ ] 필요한 경우 Rigidbody 설정을 최소한으로 추가한다.
- [ ] Play를 누른다.
- [ ] `Player`를 적에게 일부러 닿게 한다.
- [ ] 접촉 시 HP가 감소하는지 확인한다.
- [ ] HP가 0이 되면 사망 상태가 바로 반영되는지 확인한다.

## 6. 총알과 적 충돌 제거 구성
- [ ] `Enemy`에 피격 제거용 처리 로직을 준비한다.
- [ ] 총알 또는 적 한쪽에 `JC_DestroyOnHit`를 붙인다.
- [ ] 총알과 적이 서로 충돌했을 때 둘 다 제거되게 조건을 구현한다.
- [ ] 태그를 쓸 경우 `PlayerBullet`, `Enemy` 태그를 먼저 정리한다.
- [ ] 충돌 판정에 필요한 Collider 설정이 맞는지 다시 확인한다.
- [ ] 총알과 적이 겹쳤을 때 한 번만 처리되게 만든다.
- [ ] Play를 누른다.
- [ ] 적 방향으로 총알을 발사한다.
- [ ] 총알이 적과 닿으면 총알이 제거되는지 확인한다.
- [ ] 같은 순간 적도 제거되는지 확인한다.
- [ ] 여러 적을 배치한 뒤 반복 발사해서 충돌 처리 흐름이 안정적인지 확인한다.

## 7. 전투 씬 연결과 반복 테스트 구성
- [ ] Scene 안의 핵심 오브젝트 이름을 다시 정리한다.
- [ ] 최소 구성은 `Main Camera`, `Player`, `BulletSpawnPoint`, `Enemy`들로 맞춘다.
- [ ] 필요하면 빈 오브젝트를 하나 만들고 이름을 `GameplayBinder`로 정한다.
- [ ] `GameplayBinder`에 `JC_GameplaySceneBinder`를 붙인다.
- [ ] `JC_GameplaySceneBinder`에 플레이어, 총알 프리팹, 적 확인용 참조를 연결한다.
- [ ] Inspector에서 비어 있는 참조가 없는지 확인한다.
- [ ] Play를 누른 직후 이동, 발사, 적 추적이 모두 한 화면에서 보이는지 확인한다.
- [ ] 총알 명중과 플레이어 피격을 같은 Scene에서 연속으로 확인한다.
- [ ] 10초 안에 이동, 발사, 회피, 피격, 적 제거가 반복 검증되는지 본다.
- [ ] 테스트 중 불필요한 디버그 도구 없이도 전투 흐름이 읽히는지 확인한다.
- [ ] 수정이 필요하면 Task 번호 순서대로 다시 돌아가서 조정한다.

## 8. 최종 확인
- [ ] `Player` 이동이 즉시 반응하는지 다시 확인한다.
- [ ] 발사 위치가 안정적으로 유지되는지 다시 확인한다.
- [ ] 총알이 화면 밖에서 정리되는지 다시 확인한다.
- [ ] 적이 플레이어를 단순하고 명확하게 추적하는지 다시 확인한다.
- [ ] 적 접촉 시 플레이어 HP가 줄어드는지 다시 확인한다.
- [ ] 총알 명중 시 적과 총알이 함께 정리되는지 다시 확인한다.
- [ ] 한 Scene 안에서 기본 전투 루프가 반복 검증되면 현재 단계 작업을 완료 처리한다.
