# 단계별 수행 절차

현재 체크 상태는 프로젝트 파일 기준이다.
- `[x]`: 실제 구현 또는 설정이 확인된 항목
- `[ ]`: 아직 구현 또는 설정이 확인되지 않은 항목

## 0. 시작 준비
- [ ] Unity에서 테스트용 전투 Scene을 연다.
- [ ] Main Camera를 선택한다.
- [x] Camera Projection을 `Orthographic`으로 바꾼다.
- [ ] 카메라가 플레이 가능 영역을 세로 화면 기준으로 안정적으로 보이게 위치를 잡는다.
- [ ] Game View 해상도를 `768 x 1024` 기준으로 맞춘다.
- [ ] Hierarchy를 비우지 말고 기본 카메라만 유지한다.

## 1. 플레이어 이동 구성
- [ ] Hierarchy에서 Capsule 오브젝트를 만든다.
- [x] 오브젝트 이름을 `Player`로 바꾼다.
- [x] `Player`의 위치를 Scene 중앙 근처로 옮긴다.
- [x] `Player`의 Z 값을 작업 중 고정값으로 정한다.
- [x] `Player`에 `JC_PlayerController`를 붙인다.
- [x] Inspector에서 이동 속도 값을 바로 조절할 수 있게 설정한다.
- [x] 스크립트가 `Horizontal`, `Vertical` 입력을 읽도록 구현한다.
- [x] 이동 계산은 X, Y만 바꾸고 Z는 유지되게 처리한다.
- [x] 대각선 이동 속도가 과하게 빨라지지 않게 방향 벡터를 정규화한다.
- [ ] Play를 누른다.
- [ ] 방향키 또는 WASD로 `Player`를 움직인다.
- [ ] `Player`가 XY 평면에서만 움직이는지 확인한다.
- [ ] 입력을 떼면 즉시 멈추는지 확인한다.

## 2. 플레이어 발사 구성
- [x] `Player` 아래에 빈 오브젝트를 만든다.
- [x] 오브젝트 이름을 `BulletSpawnPoint`로 바꾼다.
- [x] `BulletSpawnPoint`를 `Player`의 앞쪽, 화면 위 방향에 배치한다.
- [x] `BulletSpawnPoint`에 `JC_BulletSpawnPoint`를 붙인다.
- [x] `Player`에 `JC_PlayerShooter`를 붙인다.
- [x] 발사 입력 키를 Old Input 기준으로 정한다.
- [x] `JC_PlayerShooter`에 총알 프리팹 참조 칸을 만든다.
- [x] `JC_PlayerShooter`에 발사 간격 값을 Inspector에서 조절 가능하게 만든다.
- [x] `JC_PlayerShooter`가 `BulletSpawnPoint` 위치에서 총알을 생성하게 구현한다.
- [x] 총알 발사 방향은 화면 위쪽으로 고정한다.
- [ ] Play를 누른다.
- [ ] 이동 중에 발사 입력을 눌러 본다.
- [ ] 총알이 `Player` 몸통이 아니라 `BulletSpawnPoint` 위치에서 생성되는지 확인한다.
- [ ] 연속 입력 시 발사 간격이 적용되는지 확인한다.

## 3. 플레이어 총알 이동과 정리 구성
- [ ] Sphere 또는 작은 Capsule로 총알용 오브젝트를 만든다.
- [x] 오브젝트 이름을 `PlayerBullet`로 바꾼다.
- [x] `PlayerBullet`에 `JC_PlayerBullet`을 붙인다.
- [x] `JC_PlayerBullet`에 이동 속도 값을 Inspector에 노출한다.
- [x] `JC_PlayerBullet`이 생성 직후 화면 위쪽으로 전진하게 구현한다.
- [x] 총알 이동도 프레임 독립적으로 처리한다.
- [x] 화면 밖으로 나간 총알을 제거하는 조건을 넣는다.
- [x] `PlayerBullet`를 프리팹으로 저장한다.
- [x] `JC_PlayerShooter`의 총알 프리팹 칸에 이 프리팹을 연결한다.
- [ ] Play를 누른다.
- [ ] 여러 번 발사해서 총알이 같은 방향으로 계속 나가는지 확인한다.
- [ ] 총알 속도가 프레임에 따라 달라지지 않는지 확인한다.
- [ ] 화면 밖 총알이 계속 남지 않고 정리되는지 확인한다.

## 4. 적 추적 이동 구성
- [x] Cube 또는 Capsule로 적 오브젝트를 만든다.
- [x] 오브젝트 이름을 `Enemy`로 바꾼다.
- [x] `Enemy`를 `Player`와 떨어진 위치에 둔다.
- [x] `Enemy`에 `JC_EnemyController`를 붙인다.
- [x] `Enemy`에 `JC_EnemyTargetTracker`를 붙인다.
- [x] `JC_EnemyTargetTracker`의 대상 참조에 `Player` Transform을 연결한다.
- [x] `JC_EnemyController`에 이동 속도 값을 Inspector에서 조절 가능하게 만든다.
- [x] `JC_EnemyController`가 대상이 있으면 `Player` 방향으로 이동하게 구현한다.
- [x] 적 이동도 XY 평면만 사용하게 처리한다.
- [x] 적의 Z 값이 흔들리지 않게 고정한다.
- [ ] 필요하면 `Enemy`를 복제해서 2~3개 배치한다.
- [ ] Play를 누른다.
- [ ] `Player`를 이동시키며 적이 바로 추적 방향을 바꾸는지 확인한다.
- [ ] 여러 적이 동시에 있어도 기본 추적이 유지되는지 확인한다.

## 4A. 적 스폰 방향 고정 이동 구성
- [x] 적 이동 규칙을 추적형과 스폰 방향 고정형으로 구분해 문서화한다.
- [x] `JC_EnemyController`에 이동 모드 선택 값을 둔다.
- [x] 스폰 방향 고정형에서는 적이 생성 시 한 번만 이동 방향을 정한다.
- [x] 30% 확률이면 스폰 시점의 `Player` 방향을 사용한다.
- [x] 나머지 70% 확률이면 아래 방향(`Vector3.down`)을 사용한다.
- [x] 스폰 이후에는 살아 있는 동안 같은 방향으로만 계속 이동하게 구현한다.
- [x] 스폰 방향 고정형도 XY 평면만 사용하게 처리한다.
- [x] 스폰 방향 고정형도 적의 Z 값을 고정한다.
- [ ] Inspector에서 적 이동 모드를 `FixedSpawnDirection`으로 바꾼다.
- [ ] 같은 적 프리팹으로 여러 번 스폰해 방향 분포를 눈으로 확인한다.
- [ ] 일부 적이 플레이어 쪽으로 시작하고 나머지가 아래로 내려가는지 확인한다.
- [ ] 이동 시작 후에는 플레이어가 움직여도 방향이 바뀌지 않는지 확인한다.

## 5. 플레이어 체력과 적 접촉 피해 구성
- [x] `Player`에 체력용 컴포넌트 `JC_Health`를 붙인다.
- [x] 시작 HP 값을 Inspector에서 설정한다.
- [x] `Enemy`에 접촉 피해용 컴포넌트 `JC_DamageOnContact`를 붙인다.
- [x] 접촉 시 줄 피해 값을 Inspector에서 설정한다.
- [x] `JC_Health`에 HP 감소 함수와 사망 판정 함수를 만든다.
- [x] HP가 0 이하가 되면 사망 상태가 보이게 처리한다.
- [x] 프로토타입 단계에서는 `Player` 비활성화 또는 로그 출력 중 하나로 단순 처리한다.
- [x] `Player`와 `Enemy`에 충돌 판정이 가능한 Collider를 붙인다.
- [ ] 필요한 경우 Rigidbody 설정을 최소한으로 추가한다.
- [ ] Play를 누른다.
- [ ] `Player`를 적에게 일부러 닿게 한다.
- [ ] 접촉 시 HP가 감소하는지 확인한다.
- [ ] HP가 0이 되면 사망 상태가 바로 반영되는지 확인한다.

## 6. 총알과 적 충돌 제거 구성
- [x] `Enemy`에 피격 제거용 처리 로직을 준비한다.
- [x] 총알 또는 적 한쪽에 `JC_DestroyOnHit`를 붙인다.
- [x] 총알과 적이 서로 충돌했을 때 둘 다 제거되게 조건을 구현한다.
- [ ] 태그를 쓸 경우 `PlayerBullet`, `Enemy` 태그를 먼저 정리한다.
- [x] 충돌 판정에 필요한 Collider 설정이 맞는지 다시 확인한다.
- [x] 총알과 적이 겹쳤을 때 한 번만 처리되게 만든다.
- [ ] Play를 누른다.
- [ ] 적 방향으로 총알을 발사한다.
- [ ] 총알이 적과 닿으면 총알이 제거되는지 확인한다.
- [ ] 같은 순간 적도 제거되는지 확인한다.
- [ ] 여러 적을 배치한 뒤 반복 발사해서 충돌 처리 흐름이 안정적인지 확인한다.

## 7. 전투 씬 연결과 반복 테스트 구성
- [ ] Scene 안의 핵심 오브젝트 이름을 다시 정리한다.
- [ ] 최소 구성은 `Main Camera`, `Player`, `BulletSpawnPoint`, `Enemy`들로 맞춘다.
- [ ] 필요하면 빈 오브젝트를 하나 만들고 이름을 `GameplayBinder`로 정한다.
- [ ] `GameplayBinder`에 `JC_GameplaySceneBinder`를 붙인다.
- [ ] `JC_GameplaySceneBinder`에 플레이어, 총알 프리팹, 적 확인용 참조를 연결한다.
- [ ] Inspector에서 비어 있는 참조가 없는지 확인한다.
- [ ] Play를 누른 직후 이동, 발사, 적 추적이 모두 한 화면에서 보이는지 확인한다.
- [ ] 총알 명중과 플레이어 피격을 같은 Scene에서 연속으로 확인한다.
- [ ] 10초 안에 이동, 발사, 회피, 피격, 적 제거가 반복 검증되는지 본다.
- [ ] 테스트 중 불필요한 디버그 도구 없이도 전투 흐름이 읽히는지 확인한다.
- [ ] 수정이 필요하면 Task 번호 순서대로 다시 돌아가서 조정한다.

## 8. 적 반복 스폰 구성
- [x] 빈 오브젝트를 만들고 이름을 `EnemySpawner`로 정한다.
- [x] `EnemySpawner`에 `JC_EnemySpawner`를 붙인다.
- [x] 적 프리팹 참조를 연결한다.
- [x] 최소 스폰 시간과 최대 스폰 시간을 Inspector에서 조절 가능하게 만든다.
- [x] 기본값을 최소 1초, 최대 3초로 둔다.
- [x] 스폰 위치 기준점을 하나 이상 연결한다.
- [x] 플레이 시작 후 적이 자동으로 반복 생성되게 구현한다.
- [x] 다음 스폰 시간을 매번 랜덤 범위로 다시 계산한다.
- [ ] Play를 누른다.
- [ ] 10초 정도 플레이하며 적 생성 간격이 랜덤하게 바뀌는지 확인한다.
- [ ] 적이 반복 생성돼도 이동과 충돌 규칙이 유지되는지 확인한다.

## 9. 점수와 UI 구성
- [x] 점수 관리용 오브젝트를 만들고 `JC_ScoreManager`를 붙인다.
- [x] 점수 시작값이 0인지 확인한다.
- [x] 적 제거 처리와 점수 증가 지점을 연결한다.
- [x] Canvas를 만들고 우측 상단에 점수 텍스트를 둔다.
- [x] 점수 UI 바인더를 만들어 현재 점수를 표시한다.
- [x] 적 1마리 처치 시 점수가 1 증가하게 구현한다.
- [x] 같은 적에서 점수가 중복 증가하지 않게 만든다.
- [ ] Play를 누른다.
- [ ] 적을 여러 마리 제거하며 점수가 누락 없이 증가하는지 확인한다.
- [ ] 우측 상단 점수 UI가 전투 중에도 잘 보이는지 확인한다.

## 9A. UI 개선 요청
- [x] `JC_Health`가 플레이어 하위에 월드 스페이스 체력 Slider를 만들도록 반영한다.
- [x] 체력 값이 바뀔 때 Slider UI가 즉시 갱신되도록 연결한다.
- [x] 점수 UI를 `TextMeshProUGUI` 기반으로 전환한다.
- [x] 점수 Canvas가 기준 해상도 `768 x 1024`에 맞춰 스케일되도록 조정한다.
- [ ] 플레이어 이동 중에도 체력 UI가 자연스럽게 따라오는지 확인한다.
- [ ] 적 접촉 피해 시 체력 Slider가 정상적으로 감소하는지 확인한다.
- [ ] 점수 TMP UI가 우측 상단에서 전투 중에도 잘 보이는지 확인한다.

## 9B. 최고 점수와 게임오버 구성
- [x] `JC_ScoreManager`가 PlayerPrefs로 최고 점수를 저장하고 시작 시 불러오게 구현한다.
- [x] 최고 점수의 기본값이 저장 데이터가 없을 때 0점이 되게 처리한다.
- [x] 최고 점수가 갱신될 때 즉시 저장되게 처리한다.
- [x] 점수 UI 아래에 최고 점수 TMP UI를 배치한다.
- [x] `JC_Health`가 HP 0 시 사망 이벤트를 발생시키게 구현한다.
- [x] 사망 이벤트를 받는 `JC_GameOverController`가 게임오버 패널을 표시하게 구현한다.
- [x] 게임오버 패널에 제목, 재시작 버튼, 종료 버튼을 구성한다.
- [x] 재시작 버튼이 현재 Scene을 다시 불러오고 종료 버튼이 앱 종료를 요청하게 연결한다.
- [ ] Play를 누른 뒤 적을 처치하고 Scene 재시작 후에도 최고 점수가 유지되는지 확인한다.
- [ ] Play를 누른 뒤 플레이어 HP를 0으로 만들어 게임오버 UI와 두 버튼 동작을 확인한다.

## 9C. 총알 오브젝트 풀 구성
- [x] `JC_ObjectPool` 클래스를 추가해 비활성 오브젝트를 재사용하도록 구현한다.
- [x] `JC_PlayerShooter`가 시작 시 총알 풀을 미리 생성하고, 발사 시 풀에서 총알을 가져오게 연결한다.
- [x] 총알이 화면 밖으로 나가면 파괴하지 않고 풀로 반환하게 처리한다.
- [x] 총알이 적과 충돌해 제거될 때도 풀로 반환하게 처리한다.
- [x] 재사용 총알의 충돌 대기 상태가 활성화 시 초기화되게 처리한다.
- [ ] Play를 누른 뒤 연속 발사 중 총알이 정상적으로 재사용되고 충돌/화면 밖 반환이 유지되는지 확인한다.

## 10. 배경 스크롤 구성
- [x] `Assets/Texture/background.png`를 프로젝트에 둔다.
- [x] 배경용 Quad 또는 Plane을 씬에 배치한다.
- [x] 배경 머티리얼에 숲 전투 배경 텍스처를 연결한다.
- [x] `JC_BackgroundScroller`를 붙인다.
- [x] 스크롤 속도를 Inspector에서 조절 가능하게 만든다.
- [x] UV Offset으로 세로 방향 스크롤을 구현한다.
- [ ] Play를 누른다.
- [ ] 배경이 세로 방향으로 자연스럽게 흐르는지 확인한다.
- [ ] 전투 오브젝트 가독성을 해치지 않는지 확인한다.
- [ ] 텍스처 반복 이음새가 크게 거슬리지 않는지 확인한다.

## 11. 최종 확인
- [ ] `Player` 이동이 즉시 반응하는지 다시 확인한다.
- [ ] 발사 위치가 안정적으로 유지되는지 다시 확인한다.
- [ ] 총알이 화면 밖에서 정리되는지 다시 확인한다.
- [ ] 적이 플레이어를 단순하고 명확하게 추적하는지 다시 확인한다.
- [ ] 스폰 방향 고정형 적이 한 번 정한 방향을 끝까지 유지하는지 다시 확인한다.
- [ ] 적이 일정 시간마다 자동으로 생성되는지 다시 확인한다.
- [ ] 점수 UI가 우측 상단에서 잘 보이고 적 처치마다 증가하는지 다시 확인한다.
- [ ] 배경이 세로 방향으로 자연스럽게 스크롤하는지 다시 확인한다.
