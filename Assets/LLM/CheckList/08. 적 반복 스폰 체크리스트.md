# CheckList 08. 적 반복 스폰

## 사전 조건
- 적 프리팹 또는 적 오브젝트 구성이 준비되어 있다.
- 전투 씬에 스포너를 둘 위치를 정했다.

## 확인 항목
- 적이 플레이 시작 후 자동으로 생성된다.
- 생성 간격이 최소/최대 시간 범위 안에서 랜덤하게 바뀐다.
- 스폰 참조가 비어 있을 때 누락 위치를 빠르게 찾을 수 있다.
- 적이 여러 번 생성돼도 기본 이동과 충돌 규칙이 유지된다.

## 통과 기준
- 적 수급이 자동으로 이어져 전투 반복성이 생긴다.
- 다음 Task에서 점수와 UI를 붙일 흐름이 자연스럽다.
