# CheckList 02. 플레이어 발사

## 사전 조건
- Task 01의 플레이어 이동이 정상 동작한다.
- 총알 프리팹 참조가 연결되어 있다.

## 확인 항목
- 공격 입력 시 총알이 지연 없이 생성된다.
- 총알 생성 위치가 플레이어 중심과 겹치지 않는다.
- 이동 중에도 발사가 정상 동작한다.
- 연사 간격이 Inspector 설정값과 크게 다르지 않다.
- 발사 방향이 항상 화면 위쪽으로 유지된다.

## 통과 기준
- 플레이어 이동과 발사가 같은 루프 안에서 자연스럽게 이어진다.
- 다음 Task에서 총알 이동만 붙이면 테스트를 계속할 수 있다.
