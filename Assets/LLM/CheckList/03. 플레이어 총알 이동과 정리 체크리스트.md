# CheckList 03. 플레이어 총알 이동과 정리

## 사전 조건
- Task 02의 발사 기능이 정상 동작한다.
- 총알 프리팹에 이동 스크립트가 연결되어 있다.

## 확인 항목
- 총알이 생성 직후 곧바로 위쪽으로 이동한다.
- 총알 속도가 발사마다 일정하다.
- 여러 발을 동시에 발사해도 이동이 흔들리지 않는다.
- 화면 밖으로 나간 총알이 남지 않고 정리된다.
- 총알 생성과 정리 과정에서 눈에 띄는 지연이 없다.

## 통과 기준
- 총알 발사 후 궤적과 정리 흐름이 명확하게 보인다.
- 다음 Task에서 적을 배치해도 총알 동작 검증이 가능하다.
