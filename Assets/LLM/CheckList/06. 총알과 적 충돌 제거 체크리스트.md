# CheckList 06. 총알과 적 충돌 제거

## 사전 조건
- 플레이어 발사와 총알 이동이 정상 동작한다.
- 적 추적과 플레이어 접촉 피해가 이미 구현되어 있다.

## 확인 항목
- 총알이 적에 닿으면 총알이 즉시 제거된다.
- 총알이 적에 닿으면 적도 즉시 제거된다.
- 총알과 적 제거가 같은 프레임에 일어나도 오류가 없다.
- 연속 발사 중 여러 적 제거가 자연스럽게 보인다.
- 적이 플레이어에 닿았을 때 적 제거 규칙도 일관되게 유지된다.

## 통과 기준
- 기본 전투 결과가 총알 명중과 접촉 충돌 모두에서 명확하게 보인다.
- 마지막 Task에서 씬 조립과 반복 테스트만 남는다.
